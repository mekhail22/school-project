# School Attendance System

A complete attendance management system for schools, built to track student attendance and generate reports.

## 📋 Features
- Student attendance tracking
- Daily/weekly/monthly reports
- Admin dashboard
- Teacher interface
- Student records management

## 🛠️ Tech Stack
- Python
- Streamlit / Web framework

## 🚀 Run Locally
```bash
git clone https://github.com/mekhail22/school-project.git
cd school-project
pip install -r requirements.txt
streamlit run app.py
